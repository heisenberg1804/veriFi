Input
Video Input
Local path, URL (yt-dlp), or file upload → ffprobe validation + metadata
validator.py · downloader.py
Max duration configurable, extracts codec, resolution, fps, file hash
Sampling
Scene Detection
Frame differencing segmentation
scene_detector.py
cv2.absdiff with configurable threshold (default 30.0, test 5.0 for mp4v codec)
Smart Frame Selection
3-pass: diverse keyframes + transitions
frame_selector.py
1. Budget-proportional diverse selection (greedy farthest-point by histogram distance)
2. Transition frame boosting (±2 around scene boundaries)
3. Quality gate (Laplacian variance)
Quality Filter
Reject blurry frames (Laplacian)
quality_filter.py
Laplacian variance threshold — rejects frames too blurry for reliable analysis
Preprocessing
MTCNN Face Detection
Detect, align (eye-based rotation), track (IoU) → determines if Path A activates
face_detector.py · face_aligner.py · face_tracker.py
Runs on CPU, min_confidence=0.90, margin_ratio=0.3. Small faces (<80px) get neutral EfficientNet scores to avoid upscale artifacts.
Detection
Path A — Face-Level
Active only when faces detected. Runs on face crops.
FACE-SWAP & REENACTMENT
DCT 0.30 CLIP 0.20 NR 0.20 EffNet 0.15 Temporal 0.10 ChCorr 0.05
Detectors run on aligned face crops:
• CLIP ViT-L/14 zero-shot
• EfficientNet-B4 (DeepfakeBench FF++)
• DCT multi-band frequency
• Noise residual (inverted H.264 polarity)
• Cross-channel correlation (unreliable)
Path B — Frame-Level
Always active. Runs on full frames.
FULL SYNTHESIS (SORA, VEO, RUNWAY)
DCT 0.30 NR 0.25 Temporal 0.25 CLIP 0.15 ChCorr 0.05
Detectors run on full frames (resized to 224×224 for CLIP):
• CLIP ViT-L/14 zero-shot
• DCT multi-band frequency
• Noise residual
• Temporal (flow CV, SSIM, flicker, divergence)
• Cross-channel correlation
Ensemble
Weighted Ensemble Aggregation
Stronger path dominates · frame consensus override when >70% flagged · signal agreement bonus
AUTHENTIC < 0.35 SUSPICIOUS 0.35–0.70 MANIPULATED ≥ 0.70 +0.05 DCT∧NR agree −0.03 DCT⊕NR disagree
aggregator.py
Takes stronger of face/frame path. Frame consensus override forces frame dominance when >70% of frames flagged and frame_score > suspicious threshold. Signal agreement: +0.05 when both DCT and NR >0.55; −0.03 when one >0.55 and other <0.40.
Tier 2
Physics Reasoner
Multimodal LLM examines frames for shadow, reflection, perspective, anatomy violations
60% Tier 1 + 40% Physics
physics_reasoner.py
Ollama (local) or Claude API. Only runs when verdict ≠ LIKELY_AUTHENTIC. Blends 60/40 with statistical ensemble. Checks shadows, reflections, perspective, anatomy.
Explainability
GradCAM heatmaps (ViT + CNN) · 3-panel forensic views · confidence timeline
gradcam.py · heatmap_renderer.py
GradCAM on CLIP visual encoder (ViT reshape_transform) and EfficientNet (standard CNN). Three-panel view: Original | GradCAM Overlay | DCT Spectrum. Confidence timeline across sampled frames.

Signal hierarchy: NR > DCT > Temporal > CLIP > ChCorr. Decision tree routes investigation strategy. Produces structured JSON forensic report with natural language explanation.

Detection Signals — Ranked by Reliability
1. Noise Residual
Statistical, no ML. Best discriminator (1/10 errors). Inverted polarity for H.264.
w: 0.25 frame / 0.20 face
2. DCT Frequency
Signal processing, no ML. Multi-band + sharpness normalization.
w: 0.30
3. Temporal
4 sub-signals: flow CV, SSIM, flicker, divergence. Content-dominated.
w: 0.25 frame / 0.10 face
4. CLIP ViT-L/14
Semantic zero-shot. Fails on photorealistic AI video.
w: 0.15
5. Cross-Channel Corr
UNRELIABLE after H.264. Real/AI ranges overlap entirely.
w: 0.05 (tiebreaker)
